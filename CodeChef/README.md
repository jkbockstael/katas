# CodeChef

CodeChef is an online learning and competition platform you can find at [codechef.com](https://www.codechef.com).

Each problem is self-contained and has to accept input on `STDIN` and return results on `STDOUT`. Because each problem is run on its own you will see a lot of code duplication among these exercises.

Files are sorted as they are on the site: by categories and by difficulty rating.

For each problem, an example input and the corresponding expected output are provided.

Example: run a solution
```bash
node avgproblem.js < avgproblem-input
```

Example: check that a solution is correct by comparing its output to the expected one
```bash
node avgproblem.js < avgproblem-input | diff avgproblem-expected -
```
